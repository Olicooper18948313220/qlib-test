# TradingView 三时段日内助手 v1

这是 Pine Script v6 **指标**，用于1分钟图上的信号观察、订单计算和提醒。它不是自动下单程序，也不是已验证盈利的回测策略。首次使用只接模拟账户。

源码：`tradingview/intraday_assistant_v1.pine`。现有 Qlib 程序不受影响。

## 当前核验状态（2026-10-14）

- 本地10项检查通过，包括公式、预算边界、夏令时、源码分隔符、已确认高周期字段和提醒去重保护。
- 已将源码粘贴到TradingView的空白Pine编辑器。点击添加到图表后，页面要求登录；**没有取得实际Pine编译成功或失败的诊断**。
- 用户选择先交付文件、稍后自行编译。因此实时提醒、图表重载一致性和10次模拟下单尚未验收。不要把本地检查当作Pine编译或盈利验证。

## 安装与运行

1. 在 TradingView 打开美股，例如 `NASDAQ:NVDA`；选择普通蜡烛图和 **1分钟**周期。建议开启盘前盘后显示，并确认实时行情权限及数据来源。
2. 打开 **Pine Editor / Pine 编辑器**，新建空白指标，将 `.pine` 全文粘贴进去；保存为“日内助手 v1”，点击 **Add to chart / 添加到图表**。
3. 核对右上角面板；应显示“1m执行 · 已确认5m/15m”或具体等待原因。错误周期、非标准K线、非USD报价、非股票／基金类型及交易所时区不是美东的标的均不会发送买入提醒。
4. 参数默认针对500美元已交收现金；先按IBKR订单预览校准买卖费用、按实时买卖报价校准价差。默认每边0.50美元、价差0.02美元**只是估计，不是读取到的账户收费或实时价差**。
5. 开盘前设置事件日、提前收市、消息暂停时段及可用现金。先完成10次模拟下单，记录完整耗时。

每张图只监控当前标的。可以把同一指标分别添加到 NVDA、AMD、GOOGL、MSFT、AMZN 图表；可负担股数不足一股时拒绝信号，不使用碎股。

## 图形与数据口径

- 1分钟用于执行观察，正式结构在常规时段5分钟数据上计算；15分钟仅用于中盘和尾盘方向。
- 请求5分钟和15分钟数据时，对返回字段全部使用历史偏移，再配合 `lookahead_on`。脚本在新5分钟区间收到上一根已完成5分钟结果，不将信号回填到过去。
- 方向判断使用该5分钟K线开始时已经完成的15分钟数据。在恰好15分钟收盘的边界，不提前把新15分钟值加入此前5分钟结构；这是保守、稳定的跨周期口径。
- VWAP按5分钟 `HLC3 × volume` 累计，是K线级近似，不是逐笔成交VWAP；当日9:30重置。EMA20连续使用常规时段5分钟K线，不每天重置。
- 所有窗口使用 `America/New_York`，自动适配夏令时，与图表显示时区无关。假日没有行情；**提前收市必须人工禁止交易**，程序没有完整交易所日历。
- 盘前为04:00–09:30，通过独立扩展时段1分钟数据源获取；昨日价位来自上一根已完成的常规时段日线。盘前缺数据时默认拒绝正式信号；人工核对后，可勾选“盘前数据缺失时：我已人工核对阻力”，并填写盘前高点，若确认无相关盘前成交可保留0。
- 有盘前数据并不证明数据完整；请核对交易所／Cboe等来源差异。人工盘前高点只在自动盘前数据缺失时使用。
- 样本未预热、昨日价位缺失、量能不足等不会产生正式买入提醒。面板显示最新状态，不是历史台账。

## 三个策略

所有时间为美东，入场窗口以**确认K线结束时间**判断。量能窗口均排除确认／突破K线本身。

| 策略 | 入场窗口 | 最迟退出 | 结构 |
|---|---|---|---|
| 开盘突破回踩 | 10:00–10:45 | 11:15 | 前30分钟区间突破、第一次回踩、重新上涨 |
| 中盘趋势回踩 | 11:15–13:30 | 14:00 | 15分钟向上、5分钟缩量回踩、重新上涨 |
| 尾盘整理突破 | 14:30–15:15 | 15:45 | 上涨方向、高位整理、放量突破、回踩确认 |

### 开盘

前30分钟必须有完整6根常规时段5分钟K线，固定最高价H和最低价L。5分钟收于H及VWAP上方，且成交量≥此前6根均量的1.5倍时进入准备。此后最多3根内等待第一次回踩：最低价触及H＋缓冲，且没有收盘跌破区间中点；阳线收盘同时超过H和前一根高点时确认。止损为突破后至确认期间最低价减缓冲。没有回踩、回踩过深、超过3根或入场窗口结束均失效。

### 中盘

最近两根已完成15分钟K线分别收于各自VWAP之上，最新收盘高于前一根，最新VWAP高于30分钟前，且三根VWAP数据属于当天。随后连续2–4根5分钟收盘逐步降低，全部收于VWAP之上，至少一根最低价触及EMA20。回踩段总量低于此前同根数段总量。下一根阳线收盘超过前一根高点时确认；止损取回踩段及确认K线最低价减缓冲。

只有1根下降后反弹不算候选，可以继续观察。首次2根及以上的下降段开始准备；超过4根、方向失效或反弹未达到确认条件后，本标的中盘不重试。此口径避免不断重选漂亮的回踩。

### 尾盘

方向条件同中盘。用突破前4根5分钟K线固定整理区间，全部收盘高于VWAP；区间宽度≤再往前6根价格范围的一半。突破K线收于上沿之外，成交量≥整理段均量的1.5倍。此后最多两根内，最低价触及上沿＋缓冲且收回上沿之上时确认。止损为整理区间下沿减缓冲。跌破VWAP／整理下沿、无回踩或超期即失效。

### 共用过滤

正式买价E为确认5分钟收盘价，止损S向下按最小报价单位取整。缓冲=max(输入价差，最小报价单位)。止盈T向上取整到 `E + 3 × (E-S)`。

在E与T之间（含T）存在昨日高点、盘前高点、确认K线之前的当日高点时拒绝。所有价位只使用当时已有数据；不会认为“目标达到过”就是实际成交。

## 数量计算及500美元边界

令D=E−S，预估买卖费用为Cb、Cs：

```text
可用本金净额 = min(本金及买入费上限, 已交收现金 − 现金缓冲) − Cb
Q = max(0, floor(min((风险预算 − Cb − Cs) / D, 可用本金净额 / E)))
计划亏损 = Q × D + Cb + Cs
计划净盈利 = Q × (T−E) − Cb − Cs
扣费后计划盈亏比 = 计划净盈利 / 计划亏损
```

默认现金500、缓冲50、本金及买入费上限450、风险预算2.50、买卖费用各0.50。例：E=40、S=39.50时，Q=3、T=41.50，本金＋买入费120.50美元，计划亏损2.50美元，计划净盈利3.50美元，**扣费后只有1.40:1**，尽管价格距离为3:1。

这说明最低费用对500美元账户有实质影响。脚本显示差异，不把价格3R当成实际净3R，不自动提高风险预算。费用按“每笔预估总额”输入，股数变化时需重新校准；模型未包括实际止损滑点、税费遗漏或部分成交带来的额外费用。止损成交可能超过计划亏损。

## 提醒设置与人工执行

创建提醒时，条件选择本指标，再选择 **Any alert() function call / 任何alert()函数调用**；通知方式按你的需求选择。不要另设“所有提醒都只在1分钟收盘”来替代脚本逻辑；准备／确认按高周期快照触发，实时失效按当前行情更新触发。

1. **准备（橙色）**：暂定价格、止损、止盈、数量，可预填订单；不是买入确认。
2. **确认（绿色）**：锁定订单卡并提醒一次。核对IBKR报价、已交收现金、数量和费用，使用固定限价＋附带止盈止损。提醒到达时已过3分钟或已越过失效价位，则拒绝，不发送买入确认。
3. **失效（灰色）**：确认后3分钟、价格到E＋0.5D、触及S、越过入场窗口或人工暂停。**这只描述候选信号，绝不代表IBKR已撤单、未成交或需要立即平仓。** 已提交订单时先核对真实状态。
4. **时间退出**：有曾通过预算的订单卡时，在对应时刻提示核对持仓；提醒不知道你是否买入。已买入时执行时间退出，确认清仓及残余卖单处理。

提交后5分钟仍未成交的期限从**你真实提交时间**开始计算，使用自己的计时器；Pine无法读取该时间。取消请求与成交可能同时发生，必须核对IBKR最终状态。

暂停、禁止交易和消息时段会阻止新的准备／确认；暂停后已有订单卡的时间退出提醒仍保留。每张图最多一张活动订单卡；不能替代跨股票账户管理。每天最多一笔实际成交；成交后暂停全部图表新买入提醒，并处理服务器提醒。

**特别注意：修改图表参数不会修改已经创建的服务器提醒。** TradingView保存创建时的脚本、参数、标的与周期快照。暂停交易时，应在提醒管理器中暂停相关旧提醒；修改现金、费用、策略、脚本后，删除／停止旧提醒并重新创建，否则旧提醒仍按旧参数运行。

倒计时和失效提醒依赖行情更新，不是独立闹钟；开盘前、停牌或断线时可能没有更新。首版不存在已成交持仓管理接口；买入后保留IBKR保护订单，图表提醒仅辅助核对。

## 验证清单

| 场景 | 预期 |
|---|---|
| 普通1分钟USD美股图 | 面板正常显示，5分钟边界最多处理一次 |
| 5分钟图、非标准K线、非USD | 不发正式买入提醒并显示周期／数据提示 |
| 未完成5分钟或15分钟 | 不产生依赖其最终数值的确认；刷新后历史确认一致 |
| E=40、S=39.50、往返费用1 | 3股，止盈41.50，计划风险2.50，净盈亏比1.40 |
| 风险不足付费／现金不足一股 | 0股，拒绝 |
| 盘前缺数据且未人工核对 | 拒绝；已人工核对才允许继续筛选 |
| 阻力位于E与T之间 | 拒绝 |
| 第3根开盘回踩／第2根尾盘回踩仍未确认 | 候选失效，不多等一根 |
| 确认后3分钟或追价阈值 | 灰色失效，提醒要求核对真实订单 |
| 历史同分钟触及两个失效价位 | 保守失效，不推测先后 |
| 参数修改、脚本更新 | 重建服务器提醒，否则不会同步 |
| 夏令时／跨日 | 窗口按美东，开盘区间与VWAP重置；EMA连续 |

本地核验命令：`python scripts/check_tradingview_assistant.py`（使用可用的Python环境）。它核验公式、时间边界、数据保护约束及源码完整性，**不是Pine编译器，也不运行TradingView状态机**。TradingView编译、图表运行和实时提醒测试必须单独报告。

用台账记录实际成交价、数量、费用、滑点、操作耗时、退出原因及跳过原因。至少完成10次模拟操作；后续独立回测版再验证120／180秒延迟和扣费期望值。首版不提供胜率或收益承诺。
