# 基准与配置接入

本文声明本次提交完成的两项工作：阶段一（沪深300 基准对照）与阶段二（YAML 配置接线）。改动不改变任何选股信号或因子公式，只新增对照与接线能力。

## 阶段一：沪深300 基准对照

### 新增内容

- `src/qlib_quant/benchmark.py`：加载指数 CSV、把基准对齐到策略交易日、计算超额指标。
- `data/benchmark/csi300.csv`：沪深300 日线（2018-07-02 至 2024-12-31，1580 根，来自腾讯行情，随仓库附带，开箱即用）。
- `scripts/fetch_csi300.py`：用标准库抓取/刷新沪深300 日线，`python scripts/fetch_csi300.py [start] [end]`。

### 新增指标（写入 summary.json 的 `benchmark` 块）

| 指标 | 含义 |
| --- | --- |
| `benchmark_cumulative_return` | 基准累计收益 |
| `benchmark_annual_return` | 基准年化收益 |
| `benchmark_max_drawdown` | 基准最大回撤 |
| `annual_excess_return` | 年化超额（策略年化 − 基准年化） |
| `information_ratio` | 信息比率（日超额均值/标准差 × √252） |
| `tracking_error_annualized` | 年化跟踪误差 |
| `excess_max_drawdown` | 超额累计曲线的最大回撤 |

回测还会额外输出 `benchmark_curve.csv`，权益曲线 PNG 上叠加沪深300（橙色）对比。

### 使用

- 默认自动加载 `data/benchmark/csi300.csv`，无需额外操作。
- `--benchmark-csv <path>` 换基准文件；`--no-benchmark` 关闭基准对照。

## 阶段二：YAML 配置接线

新增 `src/qlib_quant/config.py`，`backtest` 命令现在真正读取 `configs/`：

- `configs/portfolio.yaml` → `run_backtest` 的 `initial_cash / max_positions / commission_rate / stamp_duty_rate / slippage_bps / rebalance`（`rebalance: weekly` 映射为周五调仓）。
- `configs/signals.yaml` → `score_signals` 的 `thresholds`（阈值）与 `enabled`（启用的信号名单；未列出的信号不计分）。
- `configs/factors.yaml` → `add_technical_features` 的 `windows`（因子窗口）。

新增 CLI 参数 `--config-dir`（默认 `configs`）。之前"改配置文件不生效"的问题已解决：现在改 YAML 里的阈值、持仓数、费用、信号开关都会真正影响回测。

## 验证

- 合成数据端到端验证 15/15 通过：配置加载、基准对齐（无前导 NaN）、超额指标、`enabled=[]` 关闭全部信号、`benchmark_curve.csv` 与 `summary.json` 输出。
- 现有单元测试 `pytest tests/` 2/2 通过。
- 基准自身合理性：沪深300 2020–2024 累计约 -3.95%、最大回撤约 -45.6%，与实际一致。
