# 0708cao 信号与样本要求

本策略根据 `C模型策略-1016.xlsx` 的“主模型ZFF0708”F列逐条翻译。代码标识为 `0708cao_sig*`。旧 `legacy_v1` 规则与默认配置保留不变。当前版本只迁移个股信号，未接入板块规则、修订记录中的资金切分和市场暂停恢复规则，也未新增独立止盈止损。

## 使用

网页进入“新建回测”，将“策略信号系列”选为“Excel 新信号（0708cao）”，再勾选所需信号。新系列默认不启用信号。CLI 可在用户配置中设置：

```yaml
signals:
  version: 0708cao
  enabled:
    - 0708cao_sig9
  thresholds: {}
```

也可从 `configs/0708cao.yaml` 开始。项目按 `signals.version` 检查信号名单；新旧系列不可在同一次运行中混用。网页和 CLI 沿用相同的评分、等权组合、周频调仓和下一交易日开盘执行。

## 统一口径

- T 是收盘后信号日，之后最早在下一交易日开盘成交。样本长度包含 T，历史区间两端均包含。
- MA 是最近 N 根有效收盘均值；BBI 是 MA3、MA6、MA12、MA24 的均值；HLC3 是 `(high+low+close)/3`；VMA3 是最近3根成交量均值。
- MACD 使用连续递推 EMA(12,26,9)，`DIF=EMA12−EMA26`、`DEA=EMA9(DIF)`、`BAR=2×(DIF−DEA)`。至少76根有效历史后信号才可触发；76是最低有效门槛，递推仍使用加载到的更早历史。
- 区间HLC振幅按 `max0=(区间最高high+区间最高low+区间最高close)/3`、`min0=(区间最低high+区间最低low+区间最低close)/3`、`abs((max0−min0)/min0)` 计算。
- 公式来源优先F列，端点明确时以端点确定窗口。缺少行情、历史不足、分母无效时该条件不触发。价格使用项目当前后复权口径。

## 信号条件和最长样本

一条信号内所有条件取交集；不同信号之间取并集。每命中一条加1分。下列长度为各信号依赖因子所需最长有效样本数，已包含因子的滞后位置。

| 信号 | 条件摘要 | 最少样本 |
|---|---|---:|
| `0708cao_sig1` 底部上破1 | 成交额≥前日2倍；close>BBI；MACD DIF/DEA绝对值≤0.25且BAR在0至99；close突破T−8至T−4的最高价，区间HLC振幅≤20% | 76 |
| `0708cao_sig11` 底部上破2 | 与Sig1相同，突破区间改为T−19至T−9 | 76 |
| `0708cao_sig2` 上升趋势 | low<MA5且close>MA5；MACD满足上述条件；close>BBI且此前4期close均低于对应BBI | 76 |
| `0708cao_sig3` 上涨中继1 | HLC3连续两期回落、VMA3低于前期；MA10和close处于两者较大值±10%；MA5>MA10>MA20>MA30；v1=close、v2=T−8至T最低low，两个涨幅比率分别≥15%、≤40% | 30 |
| `0708cao_sig4` 上涨中继2 | HLC3连续两期回落、VMA3低于前期；low和MA20满足F列±5%区间公式；MACD条件；四均线多头排列 | 76 |

## 保留的原式异常

- Sig1和Sig11的区间按明确端点计算；F列“共6天”与端点数量不符，代码采用端点定义。
- Sig3保留F列两个不同分母的涨幅约束。
- Sig4的MA20接近条件保留F列公式；结果文件保留各子条件值供检查。
- Sig5的成交量条件依F列执行，即昨日量至少是今日的1.1倍；方向与“放量”文字不一致。F列中未定义的 `v2_max` 不计算。
- Sig6/7保留F列的“当前close高于20期前close”，不改写为MA250上行。Sig8不增加已删除条件。
- Sig9保留F列以近期最低价为分母的表达式。
- Sig10的F列为空，使用用户指定D列：成交量与换手率均按当日≥昨日4倍；四条均线分别高于20期前的对应均线。
- MACD绝对阈值0.25用于后复权价格，数值会受复权尺度影响，需在结果解释中保留这一限制。

启用新系列后，因子诊断面板保存全部相关数值因子及每个子条件的真假值。新增代码位于 `src/qlib_quant/factors/technical.py` 和 `src/qlib_quant/signals/zff0708.py`。
