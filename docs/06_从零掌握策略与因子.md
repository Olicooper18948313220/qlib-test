# 从零掌握策略设定、因子开发与回测

本手册按六次学习安排。先用网页完成练习，再通过 Notebook 和代码理解每一步。完成本手册后，你应能独立修改参数、写因子、接入信号、运行回测并解释账本。

> 练习结果用于理解程序，不用于判断交易策略好坏。使用后复权价格成交只是本项目的研究近似。

## 第一次：打开项目和网页

### 1. 打开项目

1. 从 Windows 开始菜单打开 VS Code，选择“文件 → 打开文件夹”，打开 `D:\qlib_quant`。
2. 左侧文件区中：`app` 是网页，`configs` 是参数，`src` 是策略和程序代码，`notebook` 是交互式练习，`runs` 是实验结果，`tests` 是代码检查。
3. `src\qlib_quant` 是 Python 包目录。外层 `D:\qlib_quant` 是整个项目，二者名称近似但用途不同。
4. 按 `Ctrl+Shift+P`，输入 `Python: Select Interpreter`，选 `D:\Anoconda3\envs\py311\python.exe`。
5. 展开 `notebook`，打开 `01_认识行情数据.ipynb`，右上角内核选择同一 py311。先重启内核，再逐格运行。

### 2. 启动网页并作第一次试跑

1. 在资源管理器打开 `D:\qlib_quant\scripts`，双击 `start_web.bat`。
2. 浏览器打开本机网页；首页显示数据库存在后，点“检查数据”。检查结束后查看首页任务状态。
3. 点“新建回测”，设置开始 `2020-01-01`、结束 `2020-02-28`、初始资金 `1000000`、最多持仓 `3`、试跑股票数 `5`、调仓日“周五”。保留原来 11 条信号和默认费用。
4. 点“启动回测”。首页任务卡显示数据检查、特征计算和回测进度。可刷新网页观察任务状态恢复。
5. 成功后点“结果与实验”，记录实验编号，查看每日权益、交易、持仓、跳过订单和生效参数；下载完整报告 ZIP。

完成标志：能够自己启动、运行和找到结果。若启动器报错，检查终端中 Python 版本及依赖信息；若网页显示数据库不存在，检查首页给出的数据库路径；任务失败则展开首页任务日志和 `runs\jobs\<编号>\result\error.log`。

## 第二次：认识行情数据

打开并从头运行 `notebook/01_认识行情数据.ipynb`。该练习只读 SQLite 行情表，不会修改数据库。项目实际数据库在 `D:\quanttrade20260207\data\stockdata\daily_hfq_repaired.db`，默认行情表为 `daily_quote`。

| 数据库字段 | 程序字段 | 含义 |
| --- | --- | --- |
| `stock_code` | `code` | 股票代码，按字符串处理 |
| `trade_date` | `date` | 行情日期 |
| `open_price` | `open` | 开盘价 |
| `high_price` | `high` | 最高价 |
| `low_price` | `low` | 最低价 |
| `close_price` | `close` | 收盘价 |
| `volume` | `volume` | 成交量 |
| `turnover` | `amount` | 成交额 |

练习会检查代码类型、同股同日重复和日期顺序，并展示一只股票的短区间行情。回测还会为每只股票加载开始日期之前所需的历史观测作为预热；预热用来计算移动均值和长窗口信号，不参与持仓和绩效统计。

完成标志：能说明一行行情是什么，数据库字段如何变成程序字段，以及预热为何必要。若导入失败，回到第一次确认项目根目录和 Notebook 内核。

## 第三次：拆解当前选股策略

打开 `notebook/02_拆解现有选股策略.ipynb` 并从头运行。程序会调用当前实际使用的信号函数，在固定五只股票上显示信号明细和目标持仓。

当前策略分五层：

1. **股票范围**：从 SQLite 行情库读取股票；教学练习按代码固定前五只。
2. **选股信号**：每条规则独立判断，每命中一条加 1 分。
3. **评分排序**：分数高的在前；同分按代码升序。
4. **组合**：候选中取最多 N 只，等权配置。
5. **执行与记账**：每周选定日期生成目标组合，下一交易日开盘按目标与实际持仓的差额交易。

### 原有 11 条信号

以下 `t` 是当前交易日；`close[t-k]` 表示向前第 k 个交易日；“前 N 期高低点”均不含当前日。

| 信号 | 条件 | 说明 |
| --- | --- | --- |
| `volume_bloom...20230111` | `volume[t] >= volume[t-1] * 3` 且 `close[t] > low[t-250:t-1]` 的最低值 | 至少 3 倍放量且高于前 250 期低点 |
| `volume_bloom...20230112` | `volume[t] >= volume[t-1] * 2` 且高于前 250 期最低价 | 至少 2 倍放量且高于长期低点 |
| `price_rise_predict...20220914` | `close[t] > close[t-5]` 且 `close[t] > close[t-10]` | 短期价格比较 |
| `price_down_predict_rise_1...` | `close[t-2] > close[t-1]` 且 `close[t] > close[t-1]` | 下跌后出现反弹 |
| `price_down_predict_rise_2...` | 上述反弹条件，且 `close[t] > close[t-3]` | 反弹还超过 3 期前 |
| `price_down_predict_rise_3...` | 上述反弹条件，且 `close[t] > close[t-5]` | 反弹还超过 5 期前 |
| `price_reach_year_rise_1...` | `close[t] > high[t-250:t-1]` 的最高值 | 突破前 250 期高点 |
| `price_reach_year_rise_2...` | `close[t] > 前 250 期最高价 * 1.03` | 超过长期高点 3% |
| `price_reach_year_rise_3...` | `close[t] > 前 250 期最高价 * 1.05` | 超过长期高点 5% |
| `price_low_above_previous_10...` | `close[t] > low[t-10:t-1]` 的最低值 | 收盘在前 10 期最低点上方 |
| `volume_enlarge_price_rise_4...` | `amount[t] >= amount[t-1] * 2` 且 `close[t] > close[t-1]` | 成交额至少翻倍且收盘上涨 |

网页中的成交量阈值填 2，表示比昨日增加 2 倍，即今日至少是昨日 3 倍。所有信号可以同时命中；并非互斥分类。

完成标志：能挑选一个真实日期，逐列说明股票为什么命中、分数是多少、是否进入最多三只的目标组合。如果固定五只没有任何股票命中，记录空候选结果，不要伪造交易。

## 第四次：调整参数与做对照实验

网页中每次只改变一个项目，完成以下实验。每次都抄下实验编号，并到结果页比较参数和成交：

| 实验 | 相对 A 的唯一修改 | 应查看 |
| --- | --- | --- |
| A | 原有 11 条信号，最多持仓 3 只 | 生效参数、基准交易和持仓 |
| B | 最多持仓数改为 1 | 调仓成交、持仓集中程度 |
| C | 关闭全部信号 | 无交易、资金保留为现金 |
| D | 只开启短期上涨信号 | 该规则命中与交易变化 |
| E | 只开启强放量信号 | 命中变化；阈值 2 与阈值 1 的差别 |

本项目使用“配置默认值 + 本次修改”生成本次有效参数。网页表单覆盖本次运行，默认参数位于 `configs`。结果的 `run_metadata.json` 保存有效配置；不要只凭收益曲线判断输入是否生效。

当前 `price_rise_min`、`price_rise_max` 尚未被信号使用；`factors.yaml` 中的 `features.expression` 是记录用配置，不会动态执行。这些项即使出现在文件里，修改它们也不会改变回测。当前直接接入的信号阈值是两个成交量阈值和本教程的均线偏离率阈值。

## 第五次：从 CLI 运行并开发第一个因子

### 使用项目已有 CLI

在 VS Code 终端运行：

```powershell
Set-Location D:\qlib_quant
$env:PYTHONPATH = "$PWD\src"
& 'D:\Anoconda3\envs\py311\python.exe' -m qlib_quant.cli backtest `
  --config .\configs\learning\baseline.yaml `
  --output runs/learning/cli_baseline
```

结束后网页刷新“结果与实验”，找到同名 CLI 实验，与网页 A 比较有效参数和账本文件。网页与 CLI 调用同一个运行服务。

### 定义与核对因子

本练习定义：

`20期均线偏离率 = 当日收盘价 / 最近20个收盘价的均值 - 1`

例如最近 20 期均值是 12，收盘价是 12.6，则偏离率为 0.05，即 5%。从 `notebook/03_开发首个因子.ipynb` 依次完成手算、真实价格核对、历史不足检查和未来数据扰动。可复用代码位于 `src/qlib_quant/factors/technical.py`，输出列名为 `ma_gap_20`。项目按股票分组计算；不足 20 条观察时值为空。

当前信号在收盘后根据截至当日的数据生成，最早在下一市场交易日开盘执行。均线包括当前收盘价，因此该因子能用于收盘后生成信号；若修改为盘中成交，就必须重新审查是否使用了当时尚不可得的数据。

完成标志：Notebook 手算与代码一致；未来日期行情被修改时，过去的特征不变化；不同股票的值互不串线。

## 第六次：将新因子接入策略并独立完成

项目提供一个默认关闭的教学信号 `learning_ma_gap`：

- 条件：`ma_gap_20 > learning_ma_gap_min`。
- 示例阈值：`0.02`，意思是当前价格比 20 期均价高 2%。
- 命中加 1 分；重用原有排序、最多持仓数和等权组合。
- 原有 11 条信号的默认开关不变。

网页可以在“新建回测”勾选“教学：收盘高于 20 期均价指定比例”并设置阈值。CLI 的教学配置在 `configs/learning/teaching_signal.yaml`。检查信号计算看 `src/qlib_quant/signals/legacy_v1.py`；所需预热窗口登记在同文件。

先运行基准配置 A，再只启用教学信号运行 B。之后将阈值从 `0.02` 改为 `0.05`，再次运行并比较有效参数、信号计数、持仓与交易。单独算出因子列不等于它已用于选股：必须确认信号勾选、阈值快照、组合候选和成交账本。

如果把窗口从 20 改成其他值，要同步改因子公式、信号使用的列、所需预热窗口、网页或配置说明和检查案例。不要只改公式常量。

### 核对账本

在结果页查看 `trades.csv`、`positions.csv` 和 `equity_curve.csv`。手动追踪一笔成交：

1. 原始成交价是该日开盘价；买卖两边的滑点按基点调整成交价。
2. 股数按 100 股整数手，按组合目标与实际持仓差额计算。
3. 佣金从现金扣；印花税只对卖出收取。
4. 每日总资产 = 现金 + 逐股持仓市值。
5. 无可用行情会跳过下单并保留持仓；估值使用最近已知收盘价时会记录陈旧状态。

手工追踪后可在 PowerShell 运行 `python scripts/audit_run.py <结果目录>` 复核账本。练习数据库所有交易状态为空，不能据此模拟真实停牌、涨跌停或真实可成交性；回测是研究近似，不是实盘结果。

### 结业练习

不按步骤提示，独立完成：写策略设定卡；只开教学信号；调整阈值、持仓数和调仓日；运行短区间；只改一个参数再运行；比较两次参数；解释一个候选与一笔交易；保存结论和实验编号。没有成交或收益为负不影响通过，操作链路和解释正确才算完成。
