## 本轮修复

- 按目标数量与实际持仓的差额调仓，先卖后买，手续费从现金扣除，滑点统一按基点计算。
- 无有效开盘价或已知停牌时跳过交易，保留持仓；无有效收盘价时使用最近已知价格并标记陈旧估值。
- 信号按股票分组计算，每只股票独立加载预热历史；预热不参与交易和绩效。行情按股票处理，试跑先固定股票子集。
- 每日权益、逐股持仓、费用、跳过订单及逐笔成交均可追溯；零交易报告保留 CSV 表头。
- 网页和 CLI 共用运行服务，提交时冻结有效参数，保留代码摘要、数据来源、日志和状态；已有实验不会覆盖。
- 数据库只读，并检查必要字段、重复行情、日期及无效价格。
- 任务并发控制、取消、进程异常恢复和网页刷新恢复；实验发现覆盖网页任务目录，历史结果单独标记。
- Windows 启动入口检查 Python 和依赖；网页提供编辑导航和完整报告下载。

## 适用边界

这次通过的是本地功能与账本验收。没有验证全市场五年回测的性能或策略有效性。当前数据库交易状态大量缺失，后复权价仍作为研究成交近似；涨跌停、公司行动现金流及真实成交可达性尚未完整建模。旧版含账本缺陷的结果保留供追溯，不作为新引擎的策略结论。
