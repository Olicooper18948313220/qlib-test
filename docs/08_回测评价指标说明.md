# 回测评价指标说明

新版评价报告随每个实验保存在 `runs/<实验编号>/evaluation/`。网页结果页按“账户绩效、交易分析、因子诊断、基准评价”查看；CLI 回测使用相同配置和计算模块。

## 账户绩效

- **复合年化收益（CAGR）**：期末账户净值相对初始资金的增长，按真实日历跨度复合年化。区间不足一年时是年化外推，不代表实际获得该收益。
- **年化波动率、Sharpe、Sortino**：以每日扣费后账户收益计算，每年按252个交易日换算。无风险收益率和 Sortino 目标收益率默认是0。
- **最大回撤**：每日净值相对此前最高点的最大跌幅；回撤表记录峰值、谷底、恢复日。未恢复时恢复日为空。
- **Calmar**：CAGR 除以最大回撤幅度。回撤为零或样本不足时显示不可计算。
- **VaR 95% / ES 95%**：历史日收益最差5%分位损失及其平均损失。至少需要100个有效日收益；它们是历史估计，不是未来损失上限。
- **滚动252日收益**：每个交易日向前252个交易日的账户净值变化；区间长度不足时为空。
- **换手率**：当天买入与卖出成交金额之和除以前一交易日总资产，采用双边口径。
- **仓位暴露**：每日持仓市值占账户总资产；报告同时列出平均/最大总暴露、空仓比例、持仓数量和最大单股权重。

15% CAGR 与15%回撤阈值只标记历史区间是否达到。历史回测结果不能保证未来收益。

## 交易分析

成交行表示一次买入或卖出的差额，不等于一笔完成交易。FIFO 配对表按先买先卖分摊佣金、印花税；完整持仓周期从单只股票仓位由零变正开始，到重新归零结束。胜率、盈亏比和 Profit Factor 按已完成周期计算。

期末未平仓数量按最后可用估值价计算浮盈亏，不伪造成交。买卖配对使用实际成交价和费用；滑点已通过成交价反映，只作为成本估计展示，不能再次从盈亏中扣除。账本核对差额为“已实现净盈亏 + 未实现净盈亏 - 账户总资产变化”，应接近0。

## 因子诊断

默认检查 `ma_gap_20`、`return_20`、`volume_ratio_1`、总评分及本次启用的信号，观察1、5、20个交易日的结果。配置中也可选择技术模块已计算的移动均线、历史高低点、其他窗口涨幅和成交额比。

因子定义沿用技术模块：`ma_n` 是含当日收盘价的 n 期均价；`return_n` 是当日收盘价相对 n 期前收盘价的涨幅；`high_max_n`、`low_min_n` 使用当日前 n 期，避免用当日高低价参与突破阈值；`volume_ratio_1`、`amount_ratio_1` 是当日相对前一条该股行情的比值。

IC 是每日横截面 Pearson 相关，Rank IC 是 Spearman 相关；ICIR 为日 IC 均值除以标准差，默认不年化。

标签收益定义为下一交易日开盘买入，持有到第 h 个交易日后的开盘卖出。因子在当日及此前计算，未来标签只用于事后评价。超出回测结束日期的标签留空；缺少目标开盘价不前向填充。连续因子输出五组远期收益，真假信号比较命中与未命中组；分组收益不含交易费用，也不表示可以建立空头组合。

每日有效横截面不足20只时不计算相关或分组统计。并列值不会被拆开；五组需要每组至少3只股票。小样本试跑仍会保存因子面板，但有效统计可能不足。压缩面板 `factor_panel.csv.gz` 包含日期、股票、因子/信号和远期标签，可下载后自行复核。

## 基准评价

基准 CSV 必须包含：

```csv
date,close
2020-01-02,100.25
2020-01-03,101.10
```

日期每日一行，收盘价必须为正数且不得重复。网页从“新建回测”的“可选基准 CSV”导入；CLI 可用 `--benchmark-csv`、`--benchmark-name`、`--benchmark-source`，或在 `configs/evaluation.yaml` 配置文件路径。名称、来源以及价格指数/全收益指数口径应如实填写。

策略交易日缺少基准行情时，基准模块标记不可用，不填充数据；其余评价仍会生成。报告保存基准文件副本和 SHA256 摘要。Alpha、Beta、跟踪误差和信息比率用每日收益计算；相对财富收益比较策略与基准的期末净值倍数。

## CLI 配置示例

```yaml
evaluation:
  enabled: true
  annualization_days: 252
  risk_free_rate: 0.0
  sortino_target_return: 0.0
  factors: [ma_gap_20, return_20, volume_ratio_1, signal_score]
  horizons: [1, 5, 20]
  min_cross_section: 20
  min_per_quantile: 3
  benchmark:
    path: data/benchmark/hs300.csv
    name: 沪深300
    source: 本地指数文件
    return_type: price
```

使用 `python -m qlib_quant.cli backtest --config configs/your_run.yaml` 执行。评价设置写入每次运行的参数快照；网页与 CLI 共用同一计算服务。
