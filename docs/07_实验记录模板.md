# 实验记录模板

- 运行时间：
- 配置文件：
- 回测区间：
- 固定股票范围：
- 代码版本或摘要：

## 假设与修改

- 对照实验编号：
- 本次唯一修改：
- 修改前的值：
- 修改后的值：
- 预期改变什么：
- 哪些内容保持相同：

## 检查结果

- 生效配置是否与预期一致：
- 信号命中数或候选情况：
- 交易笔数：
- 累计收益和最大回撤（仅作样本记录）：
- 手续费：
- 陈旧估值或跳过订单：
- 账本核对结果：

## 解释与后续

- 哪个变化最能解释结果：
- 是否能逐条解释一笔交易：
- 是否发现数据或实现问题：
- 本次结论：
- 下一次只改什么：

收益为正不是代码正确的证明，收益为负也不代表实验失败。先核对有效参数、信号、成交与每日账本，再解释表现。
