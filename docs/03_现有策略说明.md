# 现有交易策略说明

## 1. 运行结果先怎么看

`runs/full/summary.json` 的首轮结果是：2020—2024 年累计收益 `-92.91%`，年化收益 `-41.14%`，最大回撤 `-93.29%`，交易记录 7,674 条，期末持仓 7 只。这个结果只能作为当前基线的报警信号，不能直接当成策略本身的最终结论，因为回测记账和数据口径仍有待审计。

后续研究目标已经确定为：扣费后年化收益大于 40%，最大回撤小于 15%。这是一组验收目标，不是收益承诺；必须在训练区间、验证区间和样本外区间分别验证。

## 2. 当前真正执行的链路

`python -m qlib_quant.cli backtest` 会读取数据库中的股票行情，计算技术特征，然后调用 `score_signals`，再把当天信号交给组合选择器。回测按周频检查目标组合，在下一交易日开盘成交。当前入口直接调用 Python 默认值，并没有加载 `configs/factors.yaml`、`configs/signals.yaml` 或 `configs/portfolio.yaml`。

当前是一个 long-only 基线：最多持有 20 只股票，等权配置，100 股整数手，佣金率 0.03%，卖出印花税率 0.1%，滑点设为 5 个基点。价格来自后复权数据，后复权价格用于成交价只是研究近似；成交量和成交额保持未复权口径。

## 3. 11 条信号

每条规则产生一个布尔列，命中计 1 分；11 个分数相加得到 `signal_score`。当前 `signal_score > 0` 就进入候选池，按分数从高到低、股票代码从小到大排序，最多取 20 只。

| 规则 | 当前代码条件 | 直观含义 |
| --- | --- | --- |
| `volume_bloom...20230111` | 今日成交量 ≥ 昨日成交量 × 3，且收盘价高于此前250期最低价 | 强放量并脱离长期低点 |
| `volume_bloom...20230112` | 今日成交量 ≥ 昨日成交量 × 2，且收盘价高于此前250期最低价 | 较弱放量并脱离长期低点 |
| `price_rise_predict...20220914` | 收盘价高于5期前和10期前收盘价 | 短期相对上涨 |
| `price_down_predict_rise_1...` | 前两日价格关系表现为下跌，今日收盘价高于昨日 | 下跌后的第一类反弹 |
| `price_down_predict_rise_2...` | 上述反弹，并高于3期前收盘价 | 反弹得到延续 |
| `price_down_predict_rise_3...` | 上述反弹，并高于5期前收盘价 | 更强的反弹确认 |
| `price_reach_year_rise_1...` | 收盘价突破此前250期最高价 | 突破长期高点 |
| `price_reach_year_rise_2...` | 收盘价突破此前250期最高价的103% | 更强突破 |
| `price_reach_year_rise_3...` | 收盘价突破此前250期最高价的105% | 极强突破 |
| `price_low_above_previous_10...` | 收盘价高于此前10期最低价 | 没有跌破近期低点 |
| `volume_enlarge_price_rise_4...` | 今日成交额 ≥ 昨日成交额 × 2，且收盘价上涨 | 放额上涨 |

这些规则是并列加分，不是互斥分类。例如一只股票同时放量、突破年高、短期上涨，会得到多个分数。代码中保留了旧信号名称，但名称里的日期是规则来源日期，不是交易日期。

## 4. 当前交易流程

1. 在交易日 `t` 使用截至当天的行情计算信号。
2. 每周五从当天候选池选出最多20只股票。
3. 在 `t+1` 交易日开盘执行目标组合调整。
4. 不再持有的股票卖出，新增股票按目标权重买入。
5. 现金、持仓市值、佣金、印花税和滑点写入权益曲线与交易记录。

## 5. 评价前必须修复或确认的事项

- 重复买入时，当前实现会扣现金后覆盖原持仓数量，可能造成现金与持仓不一致。
- 某只股票缺少下一交易日行情时，卖出和市值估算会走近似分支，可能漏算真实持仓。
- 信号里的分组移位和滚动计算需要增加按股票边界的测试，避免不同股票之间发生滚动串线。
- 滑点的基点换算应统一检查；当前实现使用 `/100000`。
- 回测没有自动加载区间起始日前的预热行情，250期条件的可用样本会受影响。
- 后复权价格用于成交会改变价格尺度，必须把研究结果和真实交易口径分开报告。
- YAML 里的阈值和组合参数当前没有进入 CLI，修改配置文件不会自动改变这次回测。

因此，下一阶段应先修复回测账本并用小样本逐笔核对，再做因子和信号消融，最后才进行参数搜索。只有在这些检查通过后，才有资格判断是否接近“年化收益大于40%、最大回撤小于15%”。
