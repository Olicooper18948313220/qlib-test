# 旧策略如何进入新框架

`qlsignalcaochen.py` 提供具体规则，`qlsignal0.py` 提供比较器，`qlsignal1.py` 提供可复用的均线和价格语义。新项目把三层分别放在 `signals/legacy_v1.py` 和 `factors/technical.py`，不再让一个文件同时负责注册、计算、组合和交易。

当前保留 11 个主动 Caochen 信号。信号只产生 `signal_score`，组合模块再决定买多少，回测模块最后决定何时成交。这样可以单独替换因子、阈值或持仓规则。

`amount_ratio=2` 的旧实现是“今天成交量至少比昨天多 2 倍”，等价于今天 >= 昨天的 3 倍；新代码在注释中保留这个口径，避免把旧结果误读成 2 倍。
