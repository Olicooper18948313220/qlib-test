# 记账修复日志

本文声明本次提交对 `backtest/simple.py`、`signals/legacy_v1.py`、`cli.py` 三处代码的修复内容。改动目标只有一个：让 `runs/` 里的基线数字可信。本次未改动任何选股信号或因子公式本身，只修复回测记账与数据口径。

## 修复清单

### 1. 重复买入覆盖持仓（主因，导致市值单边失血）
- 位置：`src/qlib_quant/backtest/simple.py`（原第 30、47、59 行）
- 问题：调仓时只卖出"不在目标里"的股票；仍在目标里的老持仓没有被卖、也没有被保留，而是被第 59 行 `holdings[row.code] = float(shares)` 用新买股数直接覆盖——旧份额连同市值凭空消失，且第 46 行的 `available` 还把仍持有的股票市值算成可用现金，现金与持仓双重不一致。
- 修法：重写为按份额差额调仓（delta rebalance）。先卖出离开目标集的持仓，再对每只目标股计算 `target_shares`，与当前持股做差：`delta > 0` 买入差值、`delta < 0` 卖出差值、`delta == 0` 不动。任何已持仓且仍被选中的股票都不会被"清空重买"。

### 2. 缺下一交易日行情时持仓被静默吞掉
- 位置：`src/qlib_quant/backtest/simple.py`（原第 33–39、61 行）
- 问题：卖出时若股票没有下一日行情，原第 38 行 `del holdings[code]; continue` 直接删持仓且不补现金；市值计算第 61 行又把没有下一日收盘价的持仓整个排除在权益之外，导致停牌/退市/临停个股的价值凭空蒸发。
- 修法：维护 `last_price` 映射（每只持仓最近一次可得价格）。卖出兜底用最近可得价并照常回补现金；市值计算用最近可得价兜底，不再排除持仓。

### 3. 分组滚动跨股票串线
- 位置：`src/qlib_quant/signals/legacy_v1.py`（原第 43–47 行）
- 问题：`prev_low_10 / prev_low_250 / prev_high_250` 用 `g["low"].shift(1).rolling(...).min().reset_index(...)` 写法，`.rolling()` 作用在整条按 code/date 排序的序列上，滚动窗口会跨过股票边界，前 250 期信号混入上一只股票的尾部数据。
- 修法：改为组内滚动 `g["low"].transform(lambda s: s.shift(1).rolling(...).min())`，与 `factors/technical.py` 的 transform 口径统一，滚动不再跨股票。

### 4. 滑点换算错误（差 10 倍）
- 位置：`src/qlib_quant/backtest/simple.py`（原第 41、50 行）
- 问题：`slippage_bps / 100000`，5 个基点被算成 0.00005（0.5bp），比正确值少 10 倍。
- 修法：统一改为 `/ 10000`（5bp = 0.0005）。买入价上浮、卖出价下浮分别用 `1 + / 1 - slippage_bps/10000`。

### 5. 无预热行情，250 期条件样本缺失
- 位置：`src/qlib_quant/cli.py`（backtest 分支）+ `simple.py` 新增 `start` 参数
- 问题：取数从 `--start`（默认 2020-01-01）才开始，前 250 个交易日的滚动特征全是 NaN/False，起始区间无有效信号。
- 修法：`cli.py` 取数起点提前 400 天（`warmup_start`）做预热；`run_backtest` 新增 `start` 参数，只在 `start` 及之后建仓与记录权益，预热数据只用于填滚动特征。
