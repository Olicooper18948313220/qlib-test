当前研究目标是扣费后年化收益大于 40%，最大回撤小于 15%。这是待验证的研究目标，不是收益承诺。

## 先做什么

1. 双击 `scripts/start_web.bat`，脚本会寻找 Python 环境并打开本地网页。默认使用 8501；若端口已占用，会自动选择附近的空闲端口并打印实际地址。
2. 首页点击“检查数据”，查看数据库检查结果。
3. 进入“新建回测”，先选择短区间和固定股票子集试跑。
4. 在“结果与实验”核对每日持仓和交易；修改持仓上限再次运行，比较参数和结果。
5. 需要 CLI 或编辑代码时，查看上面的 V1 使用说明及网页“编辑导航”。

在 Windows 上也可以双击或在 PowerShell 执行 `scripts/run_validate.ps1` 和 `scripts/run_smoke.ps1`。

默认基线是 long-only、每周调仓、最多 20 只、等权、下一交易日开盘成交。旧项目的行业分析和 Excel 交易步骤不在新运行链路中。回测账本会按增减仓差额下单，缺少下一交易日行情时保留持仓并使用陈旧估值标记。每次运行都保存自己的参数、状态、交易和权益文件，不覆盖已有实验。

网页分为“首页”“新建回测”“结果与实验”和“编辑导航”。网页和命令行共用 `src/qlib_quant/runner.py`；默认配置来自 `configs/*.yaml`，本次表单修改会覆盖默认值。当前已接入初始资金、持仓数、调仓日、佣金、印花税、滑点、试跑股票数、11 条信号开关和两个成交量阈值；其他阈值会在页面和元数据中提示尚未接入。

## 修改接口

- `configs/factors.yaml`：因子窗口和字段。
- `configs/signals.yaml`：11 个 Caochen 信号的启用开关和阈值。
- `configs/0708cao.yaml`：CLI 选择新 `0708cao` 信号系列的配置示例，默认关闭信号。
- `configs/portfolio.yaml`：持仓数、调仓频率、费用、滑点。
- `src/qlib_quant/signals/legacy_v1.py`：信号实现；新增策略文件还需在运行服务中显式接入，仅复制或修改版本名不会切换策略。
- `src/qlib_quant/signals/zff0708.py`：ZFF0708 新信号实现；网页可单独选择该系列。
- `src/qlib_quant/factors/technical.py`：因子计算；每个函数只接受历史数据，避免未来数据泄漏。

## 数据口径

原数据库的价格是后复权，成交量和成交额是未复权口径。回测的成交价使用后复权价格只是研究近似，报告会始终标明这一点。

## 目录

`data/raw` 保存来源数据，`data/curated` 保存校验后的表，`data/qlib` 保存转换后的 Qlib 数据；`runs` 保存每次运行结果；`tests` 保存不依赖大数据库的单元测试。
